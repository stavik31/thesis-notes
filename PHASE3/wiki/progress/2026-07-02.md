# 2026-07-02 — Stage 3 retrain; the Stage 5 "fix" was necessary but insufficient; routing-config experiment

Came back to a stopped Stage 3 training run and ended up unwinding a false "bug fixed"
claim from [[wiki/progress/2026-06-30]], finding the *real* reason routes were identical
across vehicle types, and running a factorial experiment to characterise it.

**Headline:** the router does route vehicle types differently — but only once you
(a) **cap** the outlier-driven risk max and (b) **don't over-normalise away magnitude**,
and only at a **higher λ (~2)** than the current default of 0.5. Under the old config the
5 types produced **byte-for-byte identical routes**. This is real (if modest) positive
evidence for the thesis's load-bearing spatial-divergence claim.

---

## Test 0 — Stage 3 retrain verification (the run that was stopped)

Returned to find `train.py` no longer running. File-timestamp forensics showed the
completed `risk_scores.csv` (02:45) predated a 02:47 rewrite of `train.py` — i.e. the
finished run had used the **old** code, and (segment count 272k vs the true national
3.96M) was actually a leftover London test run, not a national pass.

Re-ran the **current** `train.py`. Confirmed it is the fixed version by three runtime
signatures the old code cannot print:
- `9 numeric + 1 flag` node features → the 5 per-type AADF columns are in
  (`cars_and_taxis, lgvs, all_hgvs, two_wheeled_motor_vehicles, pedal_cycles`).
- `Building history features... from [2020, 2021]` → the **HISTORY_YEARS / TARGET_YEARS**
  disjoint split (input = 2020–21 severity-weighted crash history; target = 2022–23;
  holdout = 2024). Purpose: stop the model copying its own crash-history input back out as
  the answer, and force a rule that transfers forward in time (the Stage 6 skill).
- `Training up to 300 epochs` (old default 200).

**Result:** early stop at **epoch 67, best val loss 0.0730**. `risk_scores.csv` regenerated:
19,805,385 rows (3.96M segments × 5 types). Per-type mean risk now differs by ~an order of
magnitude (motorcycle/cycle ≫ car/lgv/hgv) — the type-conditioning is doing something. The
`divide by zero` warning at extraction is harmless (`np.where` discards the offending rows).

## Test 1 — Stage 4 re-run (CLQ + filtered surface)

Ran `stage4_risk_surface/filter_and_clq.py` on the fresh scores. **CLQ: 0/10 type-pairs
diverge (all co-locate strongly, CLQ 3.7–5.9).** Read carefully, this says the **top-15%
hotspots** of each type overlap heavily — it does *not* say the full continuous surfaces are
identical, and routing sees the full surface along a corridor, not just hotspot overlap. So
CLQ co-location is a caution flag on the niche, not a death sentence — but it foreshadowed
the identical-routes result.

## Test 2 — Stage 5 all 5 types, same O-D → identical routes (the real finding)

Ran `route.py` for car/motorcycle/cycle/lgv/hgv on the same O-D. Summary stats *looked*
different (total_risk 0.10–0.38 by type) — which is what the 2026-06-30 note mistook for
success. But comparing the **actual segment sequences** (scratch harness, `top['path']`):

> **all 10 type-pairs 100% identical — same 64 segments, same 3.965 km.**

Only the accumulated risk *number* differed; the physical route did not. **The 2026-06-30
`risk_scores.csv` swap was necessary but insufficient** — it fixed reading a binarised
hotspot file, but a second, independent problem remained.

## Test 3 — root cause: uncapped per-type normalisation over an outlier max

In `build_graph()` the risk term is normalised `risk / max_risk[t]`, where `max_risk[t]`
is the raw `max()` over the bbox. Two compounding problems:

1. **The max is an artifact.** `risk_score = pred_count / exposure_vkm` is an **unbounded
   rate**. The segment setting car's bbox max (0.976) had `exposure_vkm = 0.414` — near-zero
   traffic (national median car exposure ≈ 207). A tiny denominator inflates the ratio; that
   noise segment becomes the normaliser for the whole bbox, crushing every real difference
   toward zero. Every type's top-5 max rows were the same low-exposure artifact pattern.
2. **Per-type scope erases magnitude.** Dividing each type by its *own* max maps all types
   onto [0,1], deleting the (real) fact that cycle/motorcycle risk is far higher in absolute
   terms than lgv.

## Test 4 — normalisation-scope and λ sweeps (isolating the cause)

- **Global norm alone (÷ one shared max):** *no change* — still 100% identical at λ=0.5.
  Because the shared max was still the uncapped artifact.
- **Capping (Stage-4 p99) + global norm at λ=0.5:** *still* identical. Capping changed the
  risk *numbers* but not the route at low λ.
- **Same, at λ=5:** routes **finally diverged** — cycle took a genuinely different path
  (~40% segment overlap with the others); car/lgv stayed together.

Key analytical insight established here: **within a single type, global vs per-type norm is
just a rescaling of λ** (a constant on the risk term = a constant on λ). So norm *scope* has
no independent effect on one type's route — it only changes the *relative* effective λ
across types. This splits the question into two channels:
- **Channel 1 (spatial divergence):** different segments risky for different types — the thesis niche.
- **Channel 2 (magnitude):** same segments, different intensity — weaker, and partly just the exposure denominator.

## Phase A — factorial experiment: `cap{off,p99} × norm{pertype,global} × λ{0…8} × 6 London routes`

Standalone harness (`route.py` untouched). Uses the **pure risk-weighted shortest path** per
type (bypassing MCDM, whose own weights would confound λ). Metric: `n_distinct` = number of
unique paths among the 5 types (1 = identical, 5 = all different); `jac` = mean pairwise
segment Jaccard. λ=0 validated: all types identical everywhere (pure-time baseline).

**Mean n_distinct across 6 routes:**

| config | λ0.5 | λ2 | λ8 |
|---|---|---|---|
| cap=**off**, per-type | 1.17 | 1.33 | 1.50 |
| cap=**off**, global | 1.00 | 1.17 | 1.33 |
| cap=**p99**, per-type | **1.83** | **2.83** | **3.67** |
| cap=**p99**, global | 1.50 | 1.50 | 2.33 |

**Findings:**
1. **Capping is THE lever, not normalisation.** Without the p99 cap, types never
   meaningfully diverge even at λ=8 (≤1.5 distinct). With it, they do. (Corrects an earlier
   guess that capping was a minor robustness tweak — it didn't matter at λ=0.5 but dominates
   at higher λ.)
2. **Per-type norm diverges *more* than global** (3.67 vs 2.33 at λ=8) — opposite of the
   prior prediction. Global norm crushes low-magnitude types (lgv, car) to ~0 effective λ so
   they collapse onto the shortest path; per-type gives every type full risk-aversion so each
   follows its own pattern → more distinct routes. (But "more distinct" ≠ "better policy" —
   per-type forces even trivially-low-risk lgv to detour; global's collapse may be more defensible.)
3. **Route geometry is a major confound.** The 2 hand-picked "cycle corridor" targets (R5,
   R6) had **flexibility 1 and 2** (≤2 possible paths in the entire sweep) → identical routes
   regardless of risk. The random-ish R1–R4 (flexibility 7–13) carried all the divergence.
   Lesson for Phase B: **pre-filter targeted routes for genuine path alternatives**, not just
   hotspot presence. The flexibility metric correctly caught this.
4. **Detours are small** (cycle max +110 m) — "different route" = parallel-street swap of
   similar length, not a dramatic reroute. Real but practically modest.
5. **Default λ=0.5 undersells it;** λ≈2 is a sensible operating point.

## Phase B — statistical confirmation (40 random routes, one central-London graph)

Random O-D pairs, two distance bands, stratified by **flexibility** (distinct paths available).
24/40 flexible; 16 geometrically constrained. Cap=p99 fixed; pure risk-weighted shortest path.
Flexible routes, per-type norm: λ=0.5 → 71% of routes diverge, λ=2 → **100%** (mean 3.96 distinct
paths /5, Jaccard 0.66). Per-type ≫ global at scale. **But magnitude is modest:** detours 30–130 m
even at λ=4; risk reduction per-type λ=2 = **7% mean, 1% median** (half of trips get ~no reduction).
Fair framing: "the risk-optimal route differs by type" holds and is reproducible, but the practical
effect is small.

## Exposure-confound check — is divergence learned, or just the traffic denominator?

`risk = pred_count / exposure_vkm`; exposure is real per-type traffic, not learned.
**Angle A (cross-type ρ):** pred_count 0.933 · risk_score 0.872 · exposure 0.773.
**Angle B (decomposition routing, λ=2, 40 routes, % routes ≥2 diverge / mean distinct):**
real `risk` 70%/2.35 · `pred` only 95%/3.88 · `expo` only 35%/1.45.
**Verdict: confound substantially refuted** — exposure structure alone gives the weakest
divergence; the GAT's `pred_count` carries it. Direct answer to "why a GAT?": exposure alone
doesn't produce type-different routes.

## Raw-data probe — is the ~0.93 similarity truth, or model-introduced?

Compared **ground-truth** per-type crash surface (2022–23) vs **model** pred_count on the same
158,237 crash-active segments. **Ground truth: ρ = −0.047, top-1k hotspot overlap 4%.**
**Model: ρ = 0.855, overlap 30%.** The data is *richly* divergent; the model smooths it away.
→ We are in the "suppressed signal" world, **not** thin-truth. Fixable.

## Smoothing-ladder diagnostic — WHERE the collapse comes from

Five surfaces, same active segments:

| surface | ρ | top-1k Jac |
|---|---|---|
| RAW 2022-23 | −0.047 | 0.042 |
| POOLED all-years (denoise) | 0.049 | 0.081 |
| +1-hop spatial smooth | 0.211 | 0.103 |
| +2-hop spatial smooth | 0.247 | 0.127 |
| GAT pred_count | **0.855** | 0.298 |

**Conclusions:** (1) divergence survives denoising → real, not sparsity noise; (2) spatial
smoothing (what message passing *is*) saturates at ρ≈0.25 → message passing is not the smoother;
(3) the 0.247→0.855 jump is **type-collapse** — a shared backbone with weak type conditioning
regressing to one common surface. **Primary fix is Stage 3 architecture (decouple the types),
not Stage 2 sparsity.** Full write-up: [[wiki/concepts/vehicle-type-risk-divergence]].

## Decisions extracted

- **THE headline problem: GAT type-collapse.** Ground-truth per-type crash surfaces are near-
  orthogonal (ρ≈0), but the GAT outputs ρ=0.855. The model is the bottleneck, not the data.
  Fix direction = decouple types (separate per-type models / strong conditioning). This
  **challenges the positioning-memo "Unified GAT with type embeddings" locked decision.**
  See [[wiki/concepts/vehicle-type-risk-divergence]].
- **The niche premise is now strongly confirmed on STATS19** (types crash in different places;
  survives denoising) — upgrades the 2026-06-22 informal probe.
- **Capping the routing risk surface at the Stage-4 p99 cap is required** (not optional). The
  raw `max()` normaliser is an exposure-artifact. See [[wiki/concepts/routing-risk-normalization]].
- **Prefer per-type normalisation for surfacing type divergence**, pending the policy question
  (should low-risk types detour at all?) and Phase B confirmation. Not yet baked into `route.py`.
- **`route.py` stays untouched until the config is settled** — all experiments run in a
  standalone harness so we can test configs the production code doesn't support.
- The 2026-06-30 "Stage 5 bug fixed" claim is **corrected**: that fix was real but only one of
  two independent causes.

## Next

1. **Fix Stage 3 type-collapse** (the real bottleneck): retrain with decoupled types —
   separate per-type models or strong type conditioning — and re-run the smoothing ladder.
   Success = pred_count ρ falls from 0.855 toward the 0.05–0.25 real-signal range.
2. **Then** revisit routing: bake cap=p99 + per-type norm + λ≈2 into `route.py` and re-measure
   divergence/detours/risk-reduction on the improved surface.
3. Grouping / EB-shrinkage (Stage 2) as a secondary denoiser if needed after the model fix.
4. Open question carried forward: cross-vehicle crash interaction — do separate per-type models
   lose the fact that crashes involve *multiple* vehicle types? (See [[wiki/concepts/vehicle-type-risk-divergence]].)
