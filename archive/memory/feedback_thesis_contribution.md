---
name: Thesis contribution standard
description: User's hard requirement — thesis contribution must use different methods/technologies, not just replicate existing work on a different dataset
type: feedback
---

Thesis contribution must never be "I did the same thing as everyone else but on a different dataset." That is explicitly not thesis worthy.

**Why:** The user needs genuine methodological novelty — different methods, different technologies, different approaches. Applying an existing pipeline to UK data instead of US data is not a contribution.

**How to apply:** When suggesting thesis directions, always anchor the contribution in a methodological or technical novelty — a new comparison nobody has done, a new technique applied to this domain, a new framing of the problem. Never pitch "same pipeline, different dataset" as the contribution, even as a component of a larger argument.
