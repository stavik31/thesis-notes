# 2026-05-26 — RAG Online Phase Complete, Presentation Prep Begins

## What was done

Built `rag/query.py` — the online phase of the RAG pipeline. The system is now end-to-end working.

**Full pipeline:**
1. Load FAISS index + metadata + collision coordinates
2. Pick a random test-split crash as the query
3. Spatial filter — haversine distance to all corpus crashes, keep within 1km
4. Semantic search — encode query narrative, FAISS search within spatial subset, return top 10
5. Prompt construction — retrieved narratives as context, fine-tuned Gemma generates warning

**Bugs fixed during build:**
- `AutoModelForCausalLM` can't load Unsloth-trained LoRA adapters — switched to `FastLanguageModel.from_pretrained` + `FastLanguageModel.for_inference`
- Test record coordinates not in metadata (metadata only has train+val) — fixed by loading coordinates directly from `collision.csv` as a separate lookup dict
- Empty generation output — caused by slicing decoded string by character length of prompt; fixed by slicing output tokens by input token length instead

**Key decisions:**
- `local_files_only=True` on sentence transformer to avoid HuggingFace network check on every run
- `torch.no_grad()` for inference — disables gradient tracking, saves memory and compute
- `model.eval()` replaced by `FastLanguageModel.for_inference()` — Unsloth's equivalent

## Current output quality

System produces location-specific warnings but they are generic ("watch out for motorcyclists", "be aware of your surroundings"). Root cause: model was fine-tuned for severity classification, not warning generation. Prompt is also too weak — doesn't force the model to reference specific factors from retrieved crashes.

## What's identified as missing

The current output is common-sense advice, not location-specific insight. The thesis argument requires surfacing **overrepresented factors** — what is statistically more likely at this specific location vs. nationally. That requires:
- Stronger prompt engineering (next step before evaluation)
- Potentially: statistical grounding from SHAP/correlation analysis feeding into the prompt
